FONTLOG for Anthropic Serif CJK Extension
==========================================

Version history
---------------

  1.000  2026-11-19  Initial CJK-only extension (31,004 code points,
                      31,724 glyphs).
  1.100  2026-11-19  Added Latin Extended, Greek and Cyrillic coverage
                      (2,173 further code points, 33,897 glyphs). This
                      entry documents both releases; the section
                      "Version 1.100 additions" below records only the
                      newer changes.
  1.100  2026-11-19  Repository restructure: the two builds are now
                      shipped as independent files in separate
                      directories (fonts/cjk-only/ and
                      fonts/multilingual/) and as separate GitHub
                      Releases. Neither build overwrites the other. No
                      font outlines, metrics or cmap entries were changed
                      in this restructure; only file placement changed.
  1.200  2026-11-19  Full build: added kana, Hangul and the remaining
                      CJK source character set (13,195 code points beyond
                      1.1.0, 47,092 glyphs / 46,963 code points in total).
                      Shipped in fonts/full/ as a third independent build
                      with its own GitHub Release. See the section
                      "Version 1.200 additions" below.
  1.000b 2026-11-19  Chinese weight variant (1.0.0-bold). Same coverage
                      as 1.0.0, but Chinese outlines taken from Noto Serif
                      CJK SC Bold instead of Medium. Shipped in
                      fonts/cjk-only-bold/ as a fourth independent build
                      with its own GitHub Release. See the section
                      "Version 1.000 CJK Bold" below.

This file records the changes made to the font software, following the
convention recommended by the SIL Open Font License FAQ for modified
fonts. It is part of the font release package together with OFL.txt.


Original material
-----------------

1. Latin outlines, OpenType layout tables, vertical metrics and internal
   naming:
   Anthropic Serif Web Text Regular, a proprietary brand typeface of
   Anthropic, PBC. 720 glyphs, 628 cmap code points, 2000 units per em,
   usWeightClass 400. GSUB features: aalt, calt, case, ccmp, dlig, dnom,
   frac, liga, locl, numr, onum, ordn, sinf, ss01, subs, sups, tnum,
   zero. GPOS features: kern, mark.

2. CJK outlines:
   Noto Serif CJK SC Medium (Source Han Serif), face index 2 of
   NotoSerifCJK-Medium.ttc, copyright (c) 2017-2022 Adobe
   (http://www.adobe.com/) and other contributors, released under the
   SIL Open Font License, Version 1.1. 65,535 glyphs, 1000 units per em,
   CFF (Type 2 charstrings) outlines.


Changes made in this project
----------------------------

Copyright (c) 2026 Moirania, for the changes listed below.

- Selected 31,004 CJK-related code points from the source cmap: the CJK
  Unified Ideographs block, Extension A, Extensions B through I,
  compatibility ideographs and their supplement, CJK punctuation,
  bopomofo, CJK strokes and radicals, ideographic description characters,
  vertical forms, CJK compatibility forms and halfwidth/fullwidth forms.
  Code points already covered by the Latin font were excluded.

- Converted each selected CFF charstring to a TrueType quadratic glyph
  with fontTools Cu2QuPen (max_err 0.5, reverse_direction enabled) so
  that the composite remains a single glyf-based TrueType font.

- Scaled all CJK outlines from 1000 to 2000 units per em to match the
  Latin font. Chinese advances were set to full-width 2000 units; Latin
  advances, side bearings and baseline metrics were left untouched.

- Appended every new glyph at the END of the glyph order so that all
  original glyph ids, and therefore every GSUB/GPOS lookup, continue to
  reference the correct glyph. No original glyph was rewritten.

- Added a (3,10) format 12 cmap subtable so that non-BMP code points in
  Extensions B through I are addressable, while keeping the existing
  format 4 and format 6 subtables intact for legacy clients.

- Updated maxp, hhea, head bounding box, OS/2 character range fields and
  post/glyph name tables to describe the enlarged character set.

- Wrote the Adobe copyright line and the SIL OFL 1.1 license reference
  into the name table (nameIDs 0, 5, 13, 14) of the composite font and
  added a note that the Reserved Font Name "Noto" is not used.

- Produced a WOFF2 build of the composite font (brotli compressed) for
  web delivery, and two specimen images showing mixed Latin/CJK setting
  and a before/after comparison against the unmodified Latin font.

- Wrote scripts/build_cjk.py so that every step above is reproducible.


Version 1.100 additions (Latin Extended, Greek, Cyrillic)
----------------------------------------------------------

Copyright (c) 2026 Moirania, for the changes listed below.

New source material:

3. Latin Extended, Greek and Cyrillic outlines:
   Noto Serif variable font from notofonts/latin-greek-cyrillic,
   Copyright 2022 The Noto Project Authors
   (https://github.com/notofonts/latin-greek-cyrillic), released under the
   SIL Open Font License, Version 1.1. 3,830 glyphs, 2,965 cmap code
   points, 1000 units per em, glyf outlines with wght 100-900 and wdth
   62.5-100 axes.

Changes:

- Instanced the variable font at wght=500 with wdth at its default 100.
  This matches the wght=500 of the CJK Medium source and keeps stem weight
  consistent across all added scripts. HVAR deltas are applied to hmtx by
  the instancer.

- Selected 2,173 further code points: 1,018 Latin Extended (including IPA,
  phonetic extensions and Extended-B through G), 354 Greek (including
  Greek Extended / polytonic), 441 Cyrillic (including Supplement and
  Extended-A/B/C), and 360 shared supporting marks (combining diacritics,
  spacing modifiers, general punctuation, superscripts, currency,
  letterlike symbols, number forms). The upstream Latin font already
  carried Latin-1 Supplement and Latin Extended-A almost in full, so those
  blocks were left untouched. See docs/CHARACTER-SET.md for the breakdown.

- Expanded composite glyphs with DecomposingRecordingPen, then scaled all
  coordinates from 1000 to 2000 units per em with TransformPen and rebuilt
  each glyph with TTGlyphPen. Decomposing removes the dependency on source
  component glyph names and prevents name collisions with the CJK uniXXXX
  names; the generated names use an lgcXXXX prefix.

- Took proportional advances from the instanced source and scaled them by
  2. The upstream Latin advances, side bearings, baseline, ascender,
  descender and cap/x heights were again left untouched.

- Continued to append every new glyph after all existing ones. The 720
  upstream glyph ids and all 19 GSUB / 2 GPOS lookups remain valid.

- Extended the format 12 cmap subtable to 33,768 entries. It now also
  carries the non-BMP Latin Extended-F (U+10780-U+107BF) and
  Latin Extended-G (U+1DF00-U+1DFFF) ranges, in addition to the CJK
  Extensions B through I. The four original cmap subtables remain intact.

- Recomputed maxp, hhea, head bounding box, OS/2 Unicode ranges and the
  name table. Added the Noto Project Authors copyright line to nameID 0,
  updated the version string to 1.100, and refreshed OFL.txt, LICENSE and
  docs/COMPLIANCE.md with the second OFL source.

- Rebuilt the WOFF2 and produced assets/multilingual-specimen.png showing
  Latin Extended, polytonic Greek, Cyrillic extensions, CJK and a mixed
  line in one frame.

Final metrics: 33,897 glyphs, 33,768 addressable code points, 2,394
non-BMP code points, highest code point U+3106C.


Version 1.200 additions (kana, Hangul, complete CJK set)
----------------------------------------------------------

Copyright (c) 2026 Moirania, for the changes listed below.

No new outline source was introduced. The same Noto Serif CJK SC Medium
(SC face index 2) that supplied the Chinese glyphs also contains kana,
Hangul and the full set of CJK enclosed / squared / box-drawing symbols;
all five faces of the TTC were checked and have identical cmap coverage,
so face 2 continues to be used for consistency with 1.0.0 and 1.1.0.

- Added the --full switch to scripts/build_cjk.py. In this mode the CJK
  selection step keeps every code point of the source cmap instead of
  only the Chinese-related ranges. The exclusion set is the actual cmap
  of the LGC source, not its nominal Unicode ranges, so characters that
  Noto Serif lacks (for example U+2160 ROMAN NUMERAL ONE) still come
  from the CJK source and no gaps are left.

- Added 13,195 code points beyond 1.1.0:
    * Hangul Syllables U+AC00-U+D7A3                        11,172
    * Hangul Jamo, Compatibility Jamo, Ext-A, Ext-B           451
    * Hiragana, Katakana, Katakana Phonetic Ext, Kanbun       221
    * Enclosed CJK, squared compatibility, enclosed ideographs  735
    * Enclosed alphanumerics, Roman numerals, box drawing      312
    * Arrows, math, geometric, misc symbols, dingbats,
      small form variants, combining enclosing marks           304
  (The last group includes 43 scattered single code points such as
  U+2423 and the U+2580-U+259F block elements.)

- Hangul syllables were taken as precomposed glyphs with a 1932-unit
  advance; kana keep the full-width 2000-unit advance already used for
  Chinese. No Jamo composition or vertical kana OpenType lookups were
  added, so the original 19 GSUB / 2 GPOS features remain untouched.

- Extended the format 12 cmap subtable to 46,963 entries, now also
  carrying U+1F100-U+1F1FF and U+1F200-U+1F2FF. The four original
  subtables remain intact; the BMP format 4 subtables now hold 44,321
  code points each.

- Recomputed maxp, hhea, head bounding box, OS/2 Unicode ranges and the
  name table. Updated the version string to "Version 1.200 Full".
  Rebuilt the TTF (23.6 MB) and WOFF2 (8.4 MB).

- Produced two new specimen sheets rendered with the 1.2.0 build:
  assets/kana-preview.png (fifty-sound table, voiced / semi-voiced /
  contracted kana, enclosed and squared forms, Japanese reading samples)
  and assets/hangul-preview.png (compatibility Jamo, syllable samples,
  enclosed Hangul, Korean reading samples and a six-script mixed line).
  Both follow the existing print-specimen style: hard 1px rules, crop
  marks, left alignment, generous margins, no rounded corners, no glass,
  no gradient buttons.

- Updated README.md, fonts/README.md, docs/BUILD.md,
  docs/CHARACTER-SET.md, docs/USAGE.md, docs/COMPLIANCE.md, LICENSE,
  CITATION.cff and CONTRIBUTING.md for the third build; created the
  v1.2.0-full GitHub Release with its own TTF and WOFF2 assets.

Final metrics: 47,092 glyphs, 46,963 addressable code points, 2,619
non-BMP code points, highest code point U+3106C.


Version 1.000 CJK Bold (Chinese weight variant)
------------------------------------------------

Copyright (c) 2026 Moirania, for the changes listed below.

Motivation: in the 1.0.0 build the Chinese (Noto Serif CJK SC Medium,
wght 500) reads thinner and paler than the upstream Western text. Measured
by rendering H and 中 at the same pixel size, the Western H stem is
61.4 px while the Medium 中 stem is 54.5 px (-11.1%). This variant makes
the Chinese deliberately heavier instead of changing the Western outlines.

Changes:

- Pointed --cjk-ttc at NotoSerifCJK-Bold.ttc (SC face index 2,
  usWeightClass 700, upem 1000, CFF outlines, 44,746 cmap code points).
  All seven weight TTCs of this family have identical cmap coverage, so
  the 31,004 selected Chinese code points are unchanged. No new outline
  source and no new licence were introduced.

- Set --no-lgc, so this build has exactly the 1.0.0 character set: no
  Greek, no Cyrillic, no Latin Extended beyond the upstream font, no
  kana, no Hangul. Added --version-string to scripts/build_cjk.py so the
  nameID 5 string reads "Version 1.000 CJK Bold" rather than being inferred
  from the build mode. Also made the attribution notice omit the LGC
  copyright sentence when the LGC source is not used.

- Verified against 1.0.0: 31,724 glyphs, 31,595 addressable code points,
  identical cmap dictionaries, identical Western glyph outlines and
  advances for all 720 upstream glyphs, identical hhea (1985 / -515 / 0),
  identical 19 GSUB and 2 GPOS features, identical 2000-unit Chinese
  advances. Only the Chinese glyf outlines differ. maxPoints rises from
  885 to 898 because the heavier contours have slightly more points.

- Measured result on the same paragraph at the same size: ink pixels
  21,178 -> 28,082 (+32.6%); 中 stem 54.5 px -> 70.7 px (+15.1% versus
  the Western H). SemiBold (60.7 px) would be the near-exact optical
  match; Bold was chosen because the brief was to fix thin, pale Chinese.
  The full seven-weight stem table is in docs/BUILD.md.

- Produced assets/cjk-weight-comparison.png with the same print-specimen
  style: two identical text blocks (Medium above, Bold below), a stem
  comparison of H / H / 中 / 中, and the measured ink-density line. Hard
  1px rules, crop marks, left alignment, generous margins, no rounded
  corners, no glass, no gradient buttons.

- Kept OS/2.usWeightClass = 400 and name ID 2 = "Regular", because the
  Western outlines and internal family are unchanged. This is a Regular
  font with heavier Chinese, not a synthetic bold face. Consequently
  fonts/cjk-only/ and fonts/cjk-only-bold/ have identical family and
  subfamily names and must never be installed together.

- Rebuilt TTF (15.3 MB) and WOFF2 (7.2 MB), updated README.md,
  fonts/README.md, docs/BUILD.md, docs/CHARACTER-SET.md, docs/USAGE.md,
  docs/COMPLIANCE.md, LICENSE, CITATION.cff and CONTRIBUTING.md for four
  builds, and created the v1.0.0-cjk-bold GitHub Release with its own
  TTF, WOFF2 and comparison image.

Final metrics: 31,724 glyphs, 31,595 addressable code points, 2,306
non-BMP code points, highest code point U+3106C.


Known limitations
-----------------

- The added outlines are matched to the Latin font by optical weight and
  metric alignment, not redrawn stroke by stroke. Chinese, kana, Hangul
  and CJK symbols retain Source Han Serif stroke detail; Greek, Cyrillic
  and Latin Extended retain Noto Serif detail. The two families share a
  design language but are not identical to the Anthropic Latin letterforms.

- Converting CFF to TrueType quadratic outlines discards the native CFF
  hinting, and decomposing the LGC composites discards their hinting
  instructions. Very small on-screen sizes may appear slightly softer.

- The original GSUB/GPOS lookups cover Latin only. Greek, Cyrillic, kana
  and Hangul get correct glyphs and advances but not Latin kerning pairs
  or language-specific substitutions. Hangul Jamo sequences are not
  recombined into syllables, and no vertical kana layout is implemented.

- The internal family name is still "Anthropic Serif Web Text" in all
  four builds, so that a build can replace the original font in an
  existing document. Install only one build at a time. The 1.0.0 and
  1.0.0-bold builds additionally share the same "Regular" subfamily and
  OS/2 weight class 400, so they are indistinguishable to a font cache.
  For a conservative redistribution, rename the internal family; see
  docs/BUILD.md.

- 1.0.0-bold makes Chinese heavier but is not a true Bold weight of the
  family. Western outlines, kerning and all OpenType features are
  identical to 1.0.0. Applying CSS font-weight: 700 on top of it would
  synthetically embolden the Latin and is not recommended.

- Colour emoji and pictographs are not included; use a dedicated emoji
  font. The U+1F200 block contributes only monochrome enclosed CJK
  ideographs.

- The 1.2.0 WOFF2 is 8.4 MB. Subsetting to the characters actually used
  by a page is strongly recommended; see docs/USAGE.md.
