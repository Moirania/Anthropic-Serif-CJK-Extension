FONTLOG for Anthropic Serif CJK Extension
==========================================

Version history
---------------

  1.000  2026-11-19  Initial CJK-only extension (31,004 code points,
                      31,724 glyphs).
  1.100  2026-11-19  Added Latin Extended, Greek and Cyrillic coverage
                      (2,173 further code points, 33,897 glyphs). This
                      entry documents both releases; the section
                      "Version 1.100 additions" below records only the
                      newer changes.
  1.100  2026-11-19  Repository restructure: the two builds are now
                      shipped as independent files in separate
                      directories (fonts/cjk-only/ and
                      fonts/multilingual/) and as separate GitHub
                      Releases. Neither build overwrites the other. No
                      font outlines, metrics or cmap entries were changed
                      in this restructure; only file placement changed.

This file records the changes made to the font software, following the
convention recommended by the SIL Open Font License FAQ for modified
fonts. It is part of the font release package together with OFL.txt.


Original material
-----------------

1. Latin outlines, OpenType layout tables, vertical metrics and internal
   naming:
   Anthropic Serif Web Text Regular, a proprietary brand typeface of
   Anthropic, PBC. 720 glyphs, 628 cmap code points, 2000 units per em,
   usWeightClass 400. GSUB features: aalt, calt, case, ccmp, dlig, dnom,
   frac, liga, locl, numr, onum, ordn, sinf, ss01, subs, sups, tnum,
   zero. GPOS features: kern, mark.

2. CJK outlines:
   Noto Serif CJK SC Medium (Source Han Serif), face index 2 of
   NotoSerifCJK-Medium.ttc, copyright (c) 2017-2022 Adobe
   (http://www.adobe.com/) and other contributors, released under the
   SIL Open Font License, Version 1.1. 65,535 glyphs, 1000 units per em,
   CFF (Type 2 charstrings) outlines.


Changes made in this project
----------------------------

Copyright (c) 2026 Moirania, for the changes listed below.

- Selected 31,004 CJK-related code points from the source cmap: the CJK
  Unified Ideographs block, Extension A, Extensions B through I,
  compatibility ideographs and their supplement, CJK punctuation,
  bopomofo, CJK strokes and radicals, ideographic description characters,
  vertical forms, CJK compatibility forms and halfwidth/fullwidth forms.
  Code points already covered by the Latin font were excluded.

- Converted each selected CFF charstring to a TrueType quadratic glyph
  with fontTools Cu2QuPen (max_err 0.5, reverse_direction enabled) so
  that the composite remains a single glyf-based TrueType font.

- Scaled all CJK outlines from 1000 to 2000 units per em to match the
  Latin font. Chinese advances were set to full-width 2000 units; Latin
  advances, side bearings and baseline metrics were left untouched.

- Appended every new glyph at the END of the glyph order so that all
  original glyph ids, and therefore every GSUB/GPOS lookup, continue to
  reference the correct glyph. No original glyph was rewritten.

- Added a (3,10) format 12 cmap subtable so that non-BMP code points in
  Extensions B through I are addressable, while keeping the existing
  format 4 and format 6 subtables intact for legacy clients.

- Updated maxp, hhea, head bounding box, OS/2 character range fields and
  post/glyph name tables to describe the enlarged character set.

- Wrote the Adobe copyright line and the SIL OFL 1.1 license reference
  into the name table (nameIDs 0, 5, 13, 14) of the composite font and
  added a note that the Reserved Font Name "Noto" is not used.

- Produced a WOFF2 build of the composite font (brotli compressed) for
  web delivery, and two specimen images showing mixed Latin/CJK setting
  and a before/after comparison against the unmodified Latin font.

- Wrote scripts/build_cjk.py so that every step above is reproducible.


Version 1.100 additions (Latin Extended, Greek, Cyrillic)
----------------------------------------------------------

Copyright (c) 2026 Moirania, for the changes listed below.

New source material:

3. Latin Extended, Greek and Cyrillic outlines:
   Noto Serif variable font from notofonts/latin-greek-cyrillic,
   Copyright 2022 The Noto Project Authors
   (https://github.com/notofonts/latin-greek-cyrillic), released under the
   SIL Open Font License, Version 1.1. 3,830 glyphs, 2,965 cmap code
   points, 1000 units per em, glyf outlines with wght 100-900 and wdth
   62.5-100 axes.

Changes:

- Instanced the variable font at wght=500 with wdth at its default 100.
  This matches the wght=500 of the CJK Medium source and keeps stem weight
  consistent across all added scripts. HVAR deltas are applied to hmtx by
  the instancer.

- Selected 2,173 further code points: 1,018 Latin Extended (including IPA,
  phonetic extensions and Extended-B through G), 354 Greek (including
  Greek Extended / polytonic), 441 Cyrillic (including Supplement and
  Extended-A/B/C), and 360 shared supporting marks (combining diacritics,
  spacing modifiers, general punctuation, superscripts, currency,
  letterlike symbols, number forms). The upstream Latin font already
  carried Latin-1 Supplement and Latin Extended-A almost in full, so those
  blocks were left untouched. See docs/CHARACTER-SET.md for the breakdown.

- Expanded composite glyphs with DecomposingRecordingPen, then scaled all
  coordinates from 1000 to 2000 units per em with TransformPen and rebuilt
  each glyph with TTGlyphPen. Decomposing removes the dependency on source
  component glyph names and prevents name collisions with the CJK uniXXXX
  names; the generated names use an lgcXXXX prefix.

- Took proportional advances from the instanced source and scaled them by
  2. The upstream Latin advances, side bearings, baseline, ascender,
  descender and cap/x heights were again left untouched.

- Continued to append every new glyph after all existing ones. The 720
  upstream glyph ids and all 19 GSUB / 2 GPOS lookups remain valid.

- Extended the format 12 cmap subtable to 33,768 entries. It now also
  carries the non-BMP Latin Extended-F (U+10780-U+107BF) and
  Latin Extended-G (U+1DF00-U+1DFFF) ranges, in addition to the CJK
  Extensions B through I. The four original cmap subtables remain intact.

- Recomputed maxp, hhea, head bounding box, OS/2 Unicode ranges and the
  name table. Added the Noto Project Authors copyright line to nameID 0,
  updated the version string to 1.100, and refreshed OFL.txt, LICENSE and
  docs/COMPLIANCE.md with the second OFL source.

- Rebuilt the WOFF2 and produced assets/multilingual-specimen.png showing
  Latin Extended, polytonic Greek, Cyrillic extensions, CJK and a mixed
  line in one frame.

Final metrics: 33,897 glyphs, 33,768 addressable code points, 2,394
non-BMP code points, highest code point U+3106C.


Known limitations
-----------------

- The added outlines are matched to the Latin font by optical weight and
  metric alignment, not redrawn stroke by stroke. Chinese retains Source
  Han Serif stroke detail; Greek, Cyrillic and Latin Extended retain Noto
  Serif detail. The two families share a design language but are not
  identical to the Anthropic Latin letterforms.

- Converting CFF to TrueType quadratic outlines discards the native CFF
  hinting, and decomposing the LGC composites discards their hinting
  instructions. Very small on-screen sizes may appear slightly softer.

- The original GSUB/GPOS lookups cover Latin only. Greek and Cyrillic get
  correct glyphs and advances but not Latin kerning pairs or
  language-specific substitutions.

- The internal family name is still "Anthropic Serif Web Text" so that the
  composite can replace the original font in an existing document. For a
  conservative redistribution, rename the internal family; see
  docs/BUILD.md.

- The full WOFF2 is 6.9 MB. Subsetting to the characters actually used by
  a page is strongly recommended; see docs/USAGE.md.
